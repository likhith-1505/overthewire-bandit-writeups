# OverTheWire: Bandit Writeups

My notes and progress through [OverTheWire's Bandit wargame](https://overthewire.org/wargames/bandit/) — 
a beginner-friendly series of Linux/security challenges designed to teach the basics of 
the command line and core security concepts.

## About Bandit

Bandit is a wargame aimed at absolute beginners. Each level requires finding a password 
hidden somewhere on the system, which grants access to the next level via SSH. It covers:

- Linux command line fundamentals
- File permissions and ownership
- Basic scripting and automation
- Networking basics
- Common security pitfalls and how to spot them

## Goal

I'm doing this to build hands-on Linux and security fundamentals as I work toward a career 
in cybersecurity, and to document my learning process publicly as part of my portfolio.

## Note on Solutions

In line with OverTheWire's guidelines, I'm **not publishing exact passwords or copy-paste 
solutions** for each level. Instead, each writeup covers the concept I learned, my approach, 
and the commands/tools involved — so it's useful without spoiling the challenge for others.
